# Document-Classification-and-Routing_DEPI

## Problem Statement
A large organization receives different types of documents—applications, complaints,
invoices, contracts, requests, and correspondence. Employees currently inspect each
document manually to determine where it should be routed.
Project Objective
Build an AI system that classifies incoming document text into predefined categories and
automatically produces a routing recommendation.

## Key Features / Scope
• Prepare a labeled document dataset.\
• Text preprocessing.\
• TF-IDF baseline.\
• Classical ML classification.\
• Compare with an LSTM/Transformer-based approach.\
• Evaluate using precision, recall, and F1.\
• Analyze difficult/misclassified documents.\
• Use Hugging Face pretrained models for the advanced version.\
• Track experiments using MLflow.\
• Package the final model for inference.
## Expected Deliverables
• Dataset\
• Text preprocessing pipeline\
• Baseline model\
• Advanced NLP model\
• Evaluation report\
• Error analysis\
• MLflow tracking\
• Inference demonstration\
• Technical architecture
## Optional Extension
Deploy the model to Azure ML and create a simple document-upload interface that sends
text to the deployed endpoint.
